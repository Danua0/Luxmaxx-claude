# Сахарное Облако — сайт кондитерской с 3D-тортами

Одностраничный сайт по продаже тортов с интерактивным 3D-конструктором на Three.js.
Без сборки и зависимостей: чистые HTML/CSS/ES-модули, Three.js подключается с CDN через import map.

## Запуск

ES-модули не работают при открытии файла напрямую (`file://`), нужен любой статический сервер:

```bash
cd cake-site
python3 -m http.server 8080
# открыть http://localhost:8080
```

Для продакшена достаточно залить папку на любой статический хостинг (GitHub Pages, Netlify, Vercel, S3).

## Что умеет

**3D-торт** (`js/cake.js`) строится процедурно, никаких моделей не грузится:
- 1–3 яруса, падают на подставку с «отскоком» при смене размера;
- бисквит, начинка, цвет покрытия (8 оттенков + свой), глазурь с подтёками;
- декор: кремовые розочки, клубника, голубика, вишня, макаруны, посыпка;
- свечи с живым мерцающим пламенем и светом, топпер с вашей надписью.

**Взаимодействие с тортом:**
- вращение мышью/пальцем, зум колёсиком/щипком, автоповорот в простое;
- клик по свече — гаснет с дымком, ещё клик — зажигается; когда погасли все — конфетти;
- «Задуть по-настоящему» — подуйте в микрофон, и свечи погаснут;
- клик по торту — отрезается кусочек и разворачивается срезом: видны слои бисквита и крема;
- клик по ягоде, макаруну или топперу — подпрыгивает; по подставке — торт делает оборот;
- подсказки при наведении, снимок торта в PNG.

**Магазин:** каталог из 6 тортов (превью рендерятся тем же 3D-движком), цена конструктора
пересчитывается на лету, корзина с сохранением в `localStorage`, оформление заказа
с маской телефона, выбором даты и скидкой за самовывоз.

**Анимации страницы:** парящий торт в hero с наклоном за курсором, 3D-наклон карточек с бликом,
появление блоков при скролле, «магнитные» кнопки, бегущая строка, полёт товара в корзину.
Учитывается `prefers-reduced-motion`, вёрстка адаптивна до 360 px.

## Структура

```
cake-site/
├── index.html        разметка и import map
├── css/style.css     дизайн-система, адаптив
└── js/
    ├── main.js       UI: каталог, конструктор, корзина, заказ
    ├── stage.js      сцена Three.js: свет, камера, OrbitControls, выбор объектов
    ├── cake.js       процедурная модель торта и все её анимации
    ├── tween.js      мини-движок твинов и easing-функций
    └── confetti.js   конфетти
```

Отправка заказа сейчас демонстрационная (без бэкенда): подключите свой API в обработчике
`#orderSubmit` в `js/main.js`. Контакты и адрес в подвале — заглушки.
